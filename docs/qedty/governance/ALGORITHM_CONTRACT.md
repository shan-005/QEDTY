# Governance contract

Governance is a cross-cutting control layer, not an authorization bypass. It enforces epistemic evidence/provenance requirements, confidence thresholds, limitations for counterfactuals, explicit allow/review/deny outcomes, and auditable assurance records.

Research/standards:
- NIST AI RMF 1.0 is organized around Govern, Map, Measure, and Manage, with governance designed as cross-cutting: https://airc.nist.gov/airmf-resources/airmf/5-sec-core/
- ISO/IEC 42001:2023 specifies requirements for an AI management system and continuous improvement: https://www.iso.org/cms/live/live/en/sites/isoorg/home/insights-news/resources/iso-42001-explained-what-it-is/MAIN%20after/row-content/row-content-col1/standards/standard-reference%40/81230.html
- OECD AI Principles were updated in 2024 and emphasize trustworthy, human-centric AI: https://www.oecd.org/en/topics/ai-principles.html
- W3C PROV-O provides an ontology for provenance interchange: https://www.w3.org/TR/prov-o/
