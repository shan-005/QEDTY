# Sources research baseline

The source layer follows the pattern used by modern data infrastructures: metadata first, stable identifiers, content hashes, version/vintage capture, bounded HTTP retrieval, and explicit normalization.

Earth-observation interoperability is aligned conceptually with NASA CMR, STAC, and OGC API Features. Economics adapters retain vintages because statistical tables can be revised. Repository-security input is intentionally treated as an observation stream and never as a source of world-model truth by itself.
