## Risk / resilience standards

- ISO 31000:2018, *Risk management — Guidelines*. Current edition as of 2026-10-06; ISO notes that a 3rd edition committee draft is under development.
- IEC 31010:2019, *Risk management — Risk assessment techniques*. Current published edition; under review.
- NIST SP 800-30 Rev. 1, *Guide for Conducting Risk Assessments*.
- NIST SP 800-160 Vol. 2 Rev. 1, *Developing Cyber-Resilient Systems*.

## Interoperability / implementation platforms

- Apache Arrow Columnar Format 1.5: language-independent columnar memory and IPC format.
- GraphBLAS C API 2.0 and current GraphBLAS C++ work: sparse linear-algebra building blocks for scalable graph kernels.
- NetworkX: broad Python graph-algorithm reference surface.
- graph-tool 3.9: C++/Boost-backed Python graph implementation useful as a performance comparison point.
- OGC API Features / JSON-FG 1.0.0: geospatial service and feature interchange boundaries.
- ASAM OpenSCENARIO 2.0.0: declarative scenario-description concepts and executable scenario campaigns; treated as a conceptual interoperability reference, not as the QEDTY domain model.
