# Seraph PCI Graph v2

This release is an executable first vertical slice of Seraph Planetary Continuity Intelligence.

## Implemented

Temporal world-graph entities and relationships, deterministic IDs, temporal validity, provenance/evidence contracts, source licensing metadata, entity resolution, JSON graph persistence, SQLite durable storage, deterministic shock propagation, continuity curves, modeled economic loss, counterfactual intervention analysis, resilience ranking, uncertainty contracts, governance claim contracts, and a synthetic GNSS → PNT → telecom timing → payment settlement → digital payments path.

The GNSS path is synthetic software validation data. It is not an empirical outage forecast.

Architecture is designed to interoperate with provenance and geospatial exchange standards rather than replacing them. Provenance uses application-level fields corresponding to the Entity/Activity/Agent pattern; geospatial ingestion is intended to use standards such as OGC API Features and newer OGC JSON-FG where appropriate.
